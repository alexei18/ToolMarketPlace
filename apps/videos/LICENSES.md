# Licenses of the assets and packages in apps/videos

Every asset that ends up in a render, and every package that makes it, with where its license was read. A music track or a sound effect without an entry here (or in its manifest) doesn't get rendered.

| Logo paths (`brand/tryworthy-logo/`) | Our own | Ours | |
| Inter, Inter Tight, JetBrains Mono (`@fontsource/*`) | npm | OFL-1.1 (`LICENSE` in each package) | 2026-11-04 |
| Sound effects | Generated by `scripts/sfx-synth.ts`; `public/sfx/manifest.json` lists source and license per type | Own work, commercial use allowed | 2026-11-04 |
| Music | `public/music/<track>.license.*` next to each track (the audio stays out of git) | must explicitly cover commercial use on social media | |

Test tracks in `public/fixtures/` are generated by `scripts/music-fixture.ts`, stay out of git and are for tests only.

## Not used

`@remotion/sfx` is not installed. Its MIT license covers only the npm code; the sounds are hosted on remotion.media with one license per sound, and many are memes built on other companies' material (SpongeBob, Windows XP, Vine, The Price Is Right).
